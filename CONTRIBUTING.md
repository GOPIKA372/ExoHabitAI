# 🤝 Contributing to ExoHabitAI

Thank you for your interest in contributing to ExoHabitAI!

ExoHabitAI is an open-source project that uses machine learning to analyze
and predict the potential habitability of exoplanets.

## 🚀 How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes locally.
6. Commit your changes with a clear message.
7. Push your branch to GitHub.
8. Open a Pull Request.

## 💡 Areas You Can Contribute

You can contribute to:

- Improving the Streamlit user interface
- Adding data visualizations
- Improving machine learning models
- Improving data preprocessing
- Adding new exoplanet features
- Fixing bugs
- Adding tests
- Improving documentation
- Improving project performance

## 🐛 Reporting Issues

If you find a bug or have an idea for improvement, please create an Issue
and clearly describe the problem or proposed feature.

## 🔀 Pull Requests

Before submitting a Pull Request:

- Make sure your changes work correctly.
- Explain what you changed.
- Keep your changes focused on one issue.
- Include screenshots when making UI changes.

Thank you for helping improve ExoHabitAI! 🚀
